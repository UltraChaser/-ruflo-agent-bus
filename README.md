# ruflo-agent-bus

Служебный репозиторий-«почтовый ящик» между сервером (panel.elrenda.ru,
доступ к нему из облачных песочниц claude.ai заблокирован сетевой
политикой окружения) и расписанными облачными агентами (elrenda-task-scout,
elrenda-elpower-marketer), которым GitHub доступен, а panel.elrenda.ru — нет.

- `data/agent-report.json`, `data/map-points.json` — сервер публикует сюда
  сам по расписанию (cron, каждые 2 часа). Агенты читают эти файлы из
  локального клона репозитория вместо прямого HTTP-запроса к панели.
- `proposals/*.json` — сюда агенты кладут свои предложения задач через
  GitHub Contents API (по одному файлу на предложение — так параллельные
  прогоны не конфликтуют). Сервер разбирает их каждые несколько минут
  (cron) и заносит в «Задачи» на panel.elrenda.ru, затем переносит файл в
  `archive/`.

Никакого кода проектов тут нет — только служебные данные для обхода
сетевого ограничения. Настроено 2026-09-13.
